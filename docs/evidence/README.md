# Evidências para Portfólio

Este diretório armazena evidências selecionadas manualmente para fins de portfólio.

## Regras

- Nada aqui é gerado automaticamente.
- Cada evidência deve ser copiada manualmente de sua origem.
- Prefira prints, relatórios em PDF/MD ou resumos — nunca código vivo.
- Arquivos aqui devem ser pequenos, autônomos e limpos (sem secrets, sem paths locais).

## Como usar

```bash
# Exemplo: copiar um relatório de teste para portfólio
cp /origem/relatorio-teste.md docs/evidence/meu-relatorio.md
```

Estrutura sugerida:

```
docs/evidence/
├── README.md
├── relatorio-backend.md
├── screenshot-arquitetura.png
└── ...
```
